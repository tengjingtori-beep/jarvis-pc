# ジャービス（PC版）v2

鳥さんの Windows パソコンで動く、**完全オフライン**のAI執事です。
常駐するのは丸い球だけ。話しかけるだけで返事をします。ボタンを押す必要はありません。

| できること | 説明 |
|---|---|
| 声で会話 | ずっと聞き耳を立てていて、話し終わると自動で返事します |
| 会話は吹き出し | 球の上に吹き出しが出て、会話が見えます（約12秒で自動で隠れます） |
| PC操作 | エージェントモードで、本物のPCを操作します（下の表） |
| 画面を見る | Vision モデルを入れると、画面を見て説明したり、見てクリックできます |
| ページを説明 | 開いているウェブページを読んで、要約や質問への答えを返します |
| 物作り | 頼むと、要素リストを確認してから、ファイルごとに作ります |
| 説明動画づくり | 紙ノート風スライド+読み上げの説明動画（NotebookLM風）を、このPCの中で作ります。無料・回数無制限 |
| 声 | VOICEVOX（無ければ Windows 標準の音声）で読み上げます。変な記号や命令文は読み上げません |
| 黒い窓なし | 中の処理は全部、窓を出さずに動きます。黒いコンソール窓は出ません |
| オフライン | 通信はこのパソコンの中（127.0.0.1）だけ。聞き耳も端末の中だけで、外に送りません |

## セットアップ（exe で終わります）

| 手順 | やること |
|---|---|
| 1 | `JarvisPC.exe` をダブルクリックして起動（これだけ） |
| 2 | 球を右クリック→「設定」を開く |
| 3 | 「モデル（GGUF）」に Sarashina などの GGUF を選ぶ。目も使うなら「目のファイル（mmproj）」も選ぶ |
| 4 | （任意）自然な声のために VOICEVOX を入れて起動しておく。無くても Windows 標準の音声で喋ります |
| 5 | （任意）設定の「Windows起動時に自動で出す」をオンにすると、PC起動時に球が出ます |

PowerShell や pip の作業は要りません。モデルのファイルは鳥さんが自分で選びます
（ダウンロードフォルダにある Sarashina の GGUF がそのまま使えます）。

## 話しかけ方（ボタンは要りません）

| やりたいこと | 言い方 |
|---|---|
| 話しかける | そのまま話すだけ。「ジャービス、」と呼びかけてからでもOK（付けなくても聞いています） |
| 仕事を止める | 「止めて」「ストップ」 |
| 静かにさせる | 「静かにして」「聞き耳を止めて」「聞くのをやめて」「ミュート」→ 静かモード（球が暗くなります） |
| また聞かせる | 静かモードの時に「聞いて」「聞き耳を始めて」「聞いてる？」 |
| 完全に止める | 球を右クリック→「聞き耳を止める（完全に）」。この状態は声では戻せません。戻す時は右クリック→「聞き耳を始める」 |

静かモードと完全停止の違い: 静かモードは「聞いて」だけを聞いています。
完全停止はマイク自体を止めるので、何も聞いていません。

正直な注意: 聞き耳はこのパソコンの中だけで動き、録音も送信もしません。
ただし、テレビの音や周りの人の声に、たまに反応してしまうことがあります。
気になる時は「静かにして」か、右クリックの完全停止を使ってください。
常時聞き耳は少しだけ CPU を使います。

自分の読み上げ中と、その後約1秒は、自分の声に反応しないようになっています。

## エージェントができるPC操作（全一覧）

| 行動 | 意味 |
|---|---|
| クリック / ダブルクリック / 右クリック / 移動 | 画面の割合（%）で指定してマウス操作 |
| ドラッグ | 押して、なめらかに動かして、離す |
| キー | enter、ctrl+c、alt+f4 など。音量キー（volume_up/down、mute）や再生キー（play_pause、next、prev）も |
| 入力 | 今フォーカスされている場所へ文字を入れる（クリップボード経由の貼り付け） |
| スクロール | マウスホイール |
| 名前をクリック | 画面に見えているボタンの名前で探して押す（UI Automation） |
| 見て / 見てクリック | 目（Vision）が設定されている時、画面を見て答える / 見て押す |
| ページ | 開いているページを読んで質問に答える |
| 前面 / 閉じる / 最大化 / 最小化 | 題名の一部でウィンドウを操作 |
| 明るさ | ノートPCの画面の明るさ（対応機種だけ） |
| スクショ | 画面の写真をジャービスのPCに保存 |
| 丸 / 線 | 本物の画面に光る丸・線を約4秒描く |
| ファイル作成 / ファイル編集 / 開く | ジャービスのPC（専用フォルダ）の中で |
| アプリ / コマンド | アプリ起動、コマンド実行（窓は出ません） |
| 待つ / おわり | 待機 / 仕事のまとめ |

音量を数値で指定する機能はありません（上げ下げと消音はキーで対応します）。

### 確認が出る時（ガード）

基本は全部自動ですが、次の時だけ確認ダイアログが出ます。

| ガード | 対象 |
|---|---|
| 買い物ガード | 購入・注文・支払・決済・買う・カート・チェックアウト・レジ・buy・pay・checkout・order に関わる操作 |
| 破壊的ガード | shutdown / Restart-Computer / Stop-Computer / logoff コマンド、ドライブの format、del /s・rd /s・Remove-Item -Recurse・rm -rf のような一括削除 |

## 物作りの作法

作り物（ゲーム・アプリ・文書など）を頼むと、ジャービスは次の順で作ります。

1. 頼まれた要素を「要素リスト」として最初に示す
2. ファイルごとに、部品を1つずつ作る
3. 最後に要素リストと照らし合わせ、入った要素と、できなかった要素を正直に報告する

作っていない要素を「ある」とは言いません。頼まれていない機能を勝手に足すこともしません。
HTML のゲームやページは、開くだけで動く単一ファイルで作ります。

### 画像と動画について（正直な線引き）

**ジャービスは写真のような画像や、実写の生成動画は作れません。**
本物らしい画像・動画の生成には大きな GPU が必要で、このパソコンでは動きません
（CPU だけだと1枚に何分もかかり、出来も大きく劣ります。実写動画は手が届きません）。
写真や実写動画が欲しい時は、これまで通りクラウドの Muse に頼んでください。
ジャービスが作るゲームやアプリは、コードで描くものです。本物の写真のような絵ではありません。

### 説明動画（NotebookLM 風）は作れます

スライド+読み上げの「説明動画」なら、このパソコンの中で全部作れます。無料で、回数の制限もありません。

| こと | 内容 |
|---|---|
| 作り方 | 吹き出しの入力欄にテーマを書いて「動画を作る」ボタン。エージェントモードでは「動画: テーマ」でも作れます |
| 中身 | 手元のモデルが台本（4〜6場面）を書き、紙ノート風のスライドに絵と箇条書きが段階的に現れ、読み上げの文に合わせて下の紙テープ字幕が切り替わります |
| 絵 | ロボット・チェックリスト・パソコン・時計など、図形で描いたモチーフを場面ごとに選びます |
| 声 | VOICEVOX（無ければ Windows 標準の音声）。声が作れなかった場面は無音になり、その旨を報告します |
| 形 | 既定は縦長 1080x1920（スマホ向け）。設定の「説明動画は縦長」を外すと横長 1280x720 |
| 置き場所 | ジャービスのPCの中に `video_<テーマ>.mp4` |

正直な線引き: 参照動画のような**手描き水彩の質感は、図形描画では再現できません**。
合わせているのは、レイアウトの整い方、字幕と声の同期、段階表示のリズム、デザインの統一感です。
台本がうまく書けなかった時は、動画をでっち上げず、その旨を伝えて止まります。

## 脳みその選び方

| モデル | 向いていること |
|---|---|
| **Sarashina2.2-Vision-3B + mmproj**（おすすめ） | 日本語の文章が一番得意で、目も持っている。1つで両方 |
| Sarashina2.2-3B | 目は要らない、文章を一番良くしたい時 |
| Sarashina2.2-1B | 速さ重視。返事が一番速い |
| Qwen2.5-VL-3B + mmproj | 目の代わりの候補 |

**正直な線引き: ChatGPT 級の賢さそのものは、このパソコンでは動きません。**
あの級のモデルはデータセンターの大きな機械で動くもので、家庭のPCには入りません。
このアプリはその代わり、日常の会話・文章作り・画面の認識・PC操作を、
無料で・オフラインで・このPCの中でやります。重い考えごとは、ChatGPT より遅く、簡単にしかできません。

## 正直な注意（できること・できないこと）

| こと | 本当のところ |
|---|---|
| 声の自然さ | VOICEVOX はとても自然ですが、「人間と完全に見分けがつかない」とまでは言えません |
| 速さ | モデルの大きさ次第。1B は速い、3B は賢いけれどこのPC（i3 / メモリ8GB）では少し遅い。目を使う処理は1回に数秒かかります |
| 画面の理解（目なし） | 目が無い時は、画面の絵は見ていません。ウィンドウの題名などから説明します |
| 名前をクリック | 標準的な作りのアプリ（Win32/UWP）が得意です。自分で絵を描くタイプのアプリやゲームでは、名前で見つけられないことがあります |
| 管理者権限の窓 | 管理者として動いているアプリの中は、ジャービスも管理者で動かさないとクリックできません（Windows の仕組み） |
| 入力の仕方 | 文字入力はクリップボード経由の貼り付けです。入力するとクリップボードの中身が置き換わります |
| ページ読み取り | 取れる文章はサイトによって部分的なことがあります。取れない時はクリップボード経由で試します（その時、一瞬だけ全選択が起き、クリップボードは元に戻します）。ページは鳥さんの画面から読むだけで、ネットへ取りには行きません |
| 明るさ | 対応していない機種（特にデスクトップ）では変えられません |
| 実機確認 | このアプリは開発機で文法とロジックのテストまで確認済みです。Windows 実機での初回起動が本番テストになります。動かない所があれば教えてください |

## ファイル構成（ソース）

| ファイル | 役割 |
|---|---|
| `app/jarvis.py` | 本体ぜんぶ（単一ファイル） |
| `app/requirements.txt` | 必要な Python ライブラリ（vosk / sounddevice / pillow / imageio-ffmpeg） |
| `app/jarvis.spec` | exe 化の設定（console=False で窓なし） |
| `.github/workflows/build.yml` | GitHub Actions で exe を作る手順（llama.cpp と Vosk モデルを同梱） |
| `tests/test_v2.py` | 純粋ロジックの単体テスト |
| `tests/test_video.py` | 説明動画づくりの単体テスト（台本パース・段階プラン・ffmpeg引数・描画の形） |

exe のデータ（設定・ジャービスのPC・ログ）は `%LOCALAPPDATA%\JarvisPC\` に置かれます。
